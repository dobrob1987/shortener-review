# Сервис сокращения ссылок

Учебный HTTP-сервис на Go. Создаёт короткие ссылки,
перенаправляет на исходные адреса и возвращает список
ссылок текущего пользователя.

## Запуск

Требуется Go 1.25.3 или новее.
Из корневой папки проекта:

```powershell
go run ./cmd/shortener
```

Адрес сервера: http://localhost:8080

Ссылки хранятся в памяти и не сохраняются после перезапуска сервиса.

## Проверка проекта

```powershell
go fmt ./...
go vet ./...
go test ./...
```

## HTTP-маршруты

| Метод | Путь | Назначение |
|---|---|---|
| POST | /api/shorten | Создать короткую ссылку |
| GET | /{id} | Перейти на исходный адрес |
| GET | /api/user/urls | Получить ссылки текущего пользователя |
| GET | /health | Проверить доступность сервиса |

## Пользователь

Пользователь определяется по подписанной cookie `user_id`.
При создании ссылки без действительной cookie сервис выдаёт новую.

Список `/api/user/urls` содержит только ссылки текущего пользователя.
Если список пуст, сервис возвращает статус 204 без тела ответа.

## Примеры запросов и ответов

### Создание короткой ссылки

POST /api/shorten

Заголовок:

```text
Content-Type: application/json
```

Тело запроса:

```json
{
  "url": "https://example.com/"
}
```

Успешный ответ — 201 Created:

```json
{
  "result": "http://localhost:8080/ABCD1234"
}
```

`ABCD1234` приведён для примера: сервис генерирует код автоматически.

Если у пользователя нет действительной cookie, сервер выдаёт
cookie `user_id` через заголовок `Set-Cookie`.

При некорректном JSON, пустом URL, неподдерживаемой схеме
или отсутствии имени хоста сервис возвращает 400 Bad Request.

### Переход по короткой ссылке

GET /ABCD1234

Если ссылка существует, сервис возвращает 307 Temporary Redirect.
В заголовке `Location` передаётся исходный адрес:

```text
Location: https://example.com/
```

Если код не найден, сервис возвращает 404 Not Found.

### Получение своих ссылок

GET /api/user/urls

В запросе нужно передать cookie `user_id`, полученную от сервера.

Успешный ответ при наличии ссылок — 200 OK:

```json
[
  {
    "short_url": "http://localhost:8080/ABCD1234",
    "original_url": "https://example.com/"
  }
]
```

Если ссылок нет, сервис возвращает 204 No Content без тела ответа.

Если cookie `user_id` имеет неправильный формат,
сервис возвращает 401 Unauthorized.
